Welcome to Client Studio.
Every client yes, on record.

Thank you for your purchase. You'll be inside your studio in about a minute. There's no account, no subscription and nothing to install: brief, content, approvals and reports in one private app.

On your computer

  1. Unzip Brief-to-Approved-Digital-Download.zip. Move the folder somewhere permanent, like Documents. Don't open files from inside the ZIP.
  2. Double-click Brief-to-Approved.html. It opens in your browser and works offline.
  3. Bookmark it. Always open it the same way, in the same browser.

On your phone or tablet

  1. Tap Open Client Studio Online below (needs internet the first time).
  2. iPhone / iPad: Safari → Share → Add to Home Screen. Android: Chrome → ⋮ → Install app.
  3. Each device keeps its own workspace. Move work between them with a backup file.

Your first minute

  1. Overview: the studio opens with a fictional practice client, Juniper Studio. Read Here's your one next step.
  2. Content: open a post and tap Run checks. Tick Facts and Rights. Approval stays locked until both are done.
  3. Approvals: tap Record decision and add who approved, when and where (email, DM). Edit approved copy and the version goes up and the yes resets.
  4. Reports: add reach and interactions; engagement rate calculates itself. Print / PDF for your client.
  5. Ready for real work? Settings → Start empty workspace, then fill in the Client Brief.

Desktop tip: press ⌘K / Ctrl+K to jump anywhere. Avatar menu → Switch theme for dark mode.

The one rule: your work lives in your browser

Client Studio saves in the browser you use, on that device. Use the same browser and the same file location. Export a backup weekly and before clearing anything: Settings → Export JSON backup. Private browsing, cleared browser data or a lost device can erase work. Your computer and your phone are separate workspaces; they don't sync. Backups may contain client information, so store them safely.

Troubleshooting

"My work is gone!" You probably opened the studio in a different browser, moved the HTML file, or used private browsing. Open it the way you did before, or Settings → Import backup. New computer or phone? Old device: Settings → Export JSON backup. New device: open the studio → Settings → Import backup. "Local save is unavailable" The browser is blocking storage (often private mode). Export a backup before closing, then open in a normal window. "Another tab changed this workspace" The studio is open twice. Export from this tab, close it, then reload the other. How do I print a report? Reports → Print / PDF. Choose Save as PDF, A4, 100% scale. Start over or see the demo again? Settings → Reset: Start empty workspace or Reload fictional demo. Export your work first. Does my client log in? No. You record approvals you received by email or DM. It is a private record, not a shared portal or e-signature.
